# DesignArena Agent Web

Landing page and onboarding guide for the DesignArena Agent &mdash; an AI partner that embeds into VS Code and the DesignArena Cloud IDE.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser. Edit content inside `src/app/page.tsx`.

## Scripts

- `npm run dev` &mdash; start the local dev server.
- `npm run build` &mdash; create a production build.
- `npm run start` &mdash; run the production server locally.
- `npm run lint` &mdash; run lint checks.

## Deployment

Deploy with Vercel using the provided production token:

```bash
vercel deploy --prod --yes --token $VERCEL_TOKEN --name agentic-aa2e8fc0
```
